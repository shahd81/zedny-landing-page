#  Zedny Landing Page

A modern and interactive landing page built with React, Tailwind CSS, and Framer Motion.

Designed to showcase a next-generation AI-powered learning platform through engaging animations, clean layouts, and a responsive user experience.

##  Highlights

* Responsive design across all devices
* Smooth page animations using Framer Motion
* Modern dark-themed interface
* Reusable and scalable component architecture
* Glassmorphism-inspired UI elements
* Interactive sections and micro-interactions
* Optimized user experience and visual hierarchy

##  Built With

* React
* Tailwind CSS
* Framer Motion
* JavaScript (ES6+)

##  Project Focus

This project focuses on creating a polished marketing experience through:

* Modern UI design principles
* Component reusability
* Animation-driven storytelling
* Responsive layouts
* Clean frontend architecture
